**Les 3 échecs restants sont de vrais constats produit** (voir P-01 à P-03).

| P-01 | ✅ **Corrigé** — Coller `# My Heading` dans un paragraphe vide donnait un paragraphe. **Décision** : un bloc collé entier (`partial: false`) dans un bloc **vide de niveau racine** adopte son type ; coller dans du texte existant ou dans un bloc imbriqué (item de liste…) ne change jamais le type | ✅ |
| P-02 | ✅ **Corrigé** — Coller `a\nb\nc\nd` donnait 1 bloc. **Décision** : au collage, 1 ligne non vide = 1 bloc (les lignes vides séparent sans créer de bloc vide). `importMarkdown` garde la sémantique CommonMark (lignes consécutives = 1 paragraphe) via `interpret(raw, nabu, { joinLines: true })`. Listes, citations, code, callouts inchangés | ✅ |
| P-03 | ✅ **Corrigé** — Ctrl+Z après un collage annulait aussi la frappe précédente. **Décision** : un collage est toujours sa propre étape d'undo, et la frappe qui suit ne fusionne pas avec lui. Mécanisme privé `#isolateNextCommits()` (merge interval à 0 pour 2 étapes, compté dans `onPush`) | ✅ |
| P-05 | ✅ **Corrigé** (règle modèle pour toute sélection repliée, `getTargetRanges` ignoré ; règle avant documentée en JSDoc) — **Suppression par mot (Ctrl+Backspace) laisse l'espace orphelin dans Chromium** : « one two three » → « one two ». Spec : `text-marks.spec.ts` A6 | ✅ |
| P-06 | ✅ **Corrigé** — option `placeholders: false | { show: 'focus'|'empty', text: {type: string|false|fn} }` (défaut `show: 'focus'`), `static placeholder` par bloc, `block.placeholder` réactif, CSS réactivé (`--nb-text-placeholder`), section README. `getPlaceholder` déprécié — **Placeholders jamais affichés** : `data-placeholder` est posé, mais les règles CSS de `Nabu.svelte:~43` sont commentées (un commentaire imbriqué casse aussi le bloc). Le CHANGELOG les annonce livrés. Spec : A3b | ✅ |
| P-07 | ✅ **Corrigé** — détection centrale dans `commit()` via `doc.getUncommittedOpsAsJson()` (ops d'arbre ou changement de `type`) ; opérations composées d'un même tour synchrone fusionnées (ex. indent) ; `handleCut` isolé explicitement — **Undo pas granulaire** : « abc », Enter, « def » en < 1 s → un seul Ctrl+Z efface tout (même regroupement temporel que P-03).
